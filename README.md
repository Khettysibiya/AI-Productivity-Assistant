# AI-Powered Productivity Assistant
Author: Khethiwe Bongiwe Sibiya

## Project Overview
This AI assistant automates workplace tasks like email drafting, meeting summarization, and task planning to save time and improve productivity.

## Features & Prompts Used

### 1. Email Generation
Prompt: Act as a professional executive assistant. Write a concise, polite follow-up email to a client who has not responded to a proposal in 5 days.

### 2. Meeting Summarization
Prompt: Summarize the meeting transcript into Key Decisions, Action Items, and Risks in bullet points under 200 words.

### 3. Task Planning
Prompt: Create a prioritized time-blocked schedule for 5 tasks using Eisenhower Matrix from 9am-5pm.

### 4. Research Assistance
Prompt: Research top 3 AI trends for small businesses in South Africa in 2026 and create a table with Trend, Benefit, Tool.

## Tools Used
ChatGPT, Gemini, GitHub

## Responsible AI
- No private data was shared
- All outputs were checked for bias and accuracy
